# Frontend

Next.js с TypeScript и App Router. Фронтенд отвечает за экраны исходных районов, выбора ровно пяти мероприятий и результата. Выбор района показывается только для мер типа «Район». Интерфейс отображает бюджет и ошибки валидации, но итоговую проверку и Score получает от API.

Контракт: [`../docs/api.md`](../docs/api.md). Начальная страница: `app/page.tsx`. В этом проекте не нужен собственный расчёт Score и не нужны серверные обработчики, дублирующие C# API.

Локальный запуск в WSL:

```bash
npm ci
npm run dev
```

Адрес приложения: `http://localhost:3000`. API при отдельном запуске: `http://localhost:8080`.
