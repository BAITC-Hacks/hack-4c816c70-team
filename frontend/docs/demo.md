# Демонстрация «Аким на 5 часов» — 2 минуты

## Подготовка

Откройте главную страницу. Убедитесь, что сценарий загрузился: видны исходный Score `52,56`, бюджет `100` и районы. Если на экране виден «Шаблонное объяснение», это серверный режим mock, а не AI-анализ.

## Сценарий для жюри

1. **0:00–0:20 — Обзор.** Покажите условную 3D-визуализацию города и подпись «Схематичная визуализация города». Выберите Нуру на обычной DOM-схеме районов: те же действия остаются доступны без WebGL.
2. **0:20–1:05 — Решения.** Перейдите в «Решения» и соберите набор: M7 — Нура, M8 — Нура, M10 — Нура, M12 — весь город, M5 — Сарыарка. Покажите ленту бюджета: потрачено `95`, остаток `5`.
3. **1:05–1:40 — Оценка.** Нажмите «Оценить». Пока идёт запрос, набор заблокирован. На результате покажите Score `52,56 → 56,54`, бюджет `95 / 100`, остаток `5` и синергию M10 + M12 в Нуре.
4. **1:40–2:00 — Объяснение.** Покажите подпись источника: `AI-анализ` означает ответ сервера с `explanationSource=llm`; `Шаблонное объяснение` означает серверный mock/fallback. Не называйте второй вариант AI-анализом.

## Если API недоступен

1. Не заменяйте ошибку успешным fixture и не обещайте результат.
2. Покажите понятную ошибку загрузки или оценки и кнопку повторной попытки.
3. Набор решений сохраняется: вернитесь к нему после восстановления API и повторите запрос.
4. Для демонстрации без сети честно ограничьтесь интерфейсом и сохранённым черновиком; результат показывайте только при фактическом ответе сервера.
