# Обязательная локализация RU / KK / EN

Новая приоритетная задача пользователя, 23 сентября 15:40. До её завершения остановить необязательную полировку. Существующие исправления сохранить, не откатывать. Три языка обязательны для сдачи; один переведённый header не считается локализацией. Срок интеграции 16:20, проверок 16:30–17:15, сдачи 17:30.

## Общий контракт — GPT публикует первым, за 10 минут

Коды: `type Locale = "ru" | "kk" | "en"`. Казахский — kk, не kz. Форматирование: ru-RU / kk-KZ / en-US. Видимые названия переключателя: РУС / ҚАЗ / ENG, доступные названия: Русский / Қазақша / English.

GPT создаёт `lib/i18n/LocaleProvider.tsx`, `lib/i18n/index.ts`, `lib/i18n/catalog.ts`. Публичный экспорт `useLocale()` возвращает `{ locale, setLocale, intlLocale }`, `LocaleProvider` принимает children; `Locale` экспортируется из index. Остальные агенты используют этот контракт, не создают собственные providers или locale state. Dictionary pattern: свой объект messages с ключами ru/kk/en в своей области; в компоненте `const {locale}=useLocale(); const copy=messages[locale]`. Параметризованные строки — функции с одинаковыми типами аргументов во всех языках. Не собирать предложения конкатенацией русских фрагментов.

Выбранный язык хранится под akim-locale. На первом запуске русский; сохранённый язык восстановить без hydration mismatch, чтение хранилища защищено try/catch. В одной вкладке все компоненты обновляются одновременно. `html.lang` и document.title соответствуют выбранному языку. Не добавлять /[locale] и не менять три существующих маршрута перед сдачей. Не добавлять библиотеку i18n и runtime-перевод через платный API. Переключение не очищает choices, не меняет revision расчёта, не запускает evaluate автоматически и не сбрасывает тему.

Каталог локализуется централизованно, по ID: 5 районов, 14 мер, 10 показателей, 5 направлений, причины трёх несовместимостей. GPT экспортирует `districtName(id, locale, fallback)`, `measureName(id, locale, fallback)`, `indicatorName(id, locale, fallback)`, `categoryName(id, locale)`, `incompatibilityReason(measureIds, locale, fallback)`. Имена не влияют на payload. Не менять исходные данные, числа, веса, правила и эффекты. Для неизвестного ID сохранять название API, не присваивать чужое. Предпочтительны display helpers в компонентах; не мутировать scenario/reducer при смене языка.
