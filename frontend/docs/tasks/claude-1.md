## Что сделать

1. Создай `styles/tokens.css` по токенам дизайн-документа и `styles/globals.css` с reset, типографикой, focus и reduced-motion. Передай GPT точные импорты для layout; сам layout не меняй.
2. Создай небольшой набор примитивов: Button, Panel, Badge, Metric, Skeleton. Экспортируй из `components/ui/index.ts`. Button сохраняет native props, disabled, type и aria-атрибуты; по умолчанию `type="button"`. Не создавай библиотеку компонентов сверх нужд продукта.
3. Создай `CityOverview` с точной сигнатурой `CityOverviewProps`; экспорт из `features/city-overview/index.ts`.
4. Обзор показывает базовый Score, бюджет и горизонт из scenario, пять районов, долю населения и десять исходных показателей выбранного района. При отсутствии районного score не вычисляй и не придумывай его.
5. Создай SVG-атлас пяти районов как авторскую схему, с подписью «Схема районов». Выбор синхронизирован с карточками через `selectedDistrictId` и `onSelectDistrict`. Не выдумывай достоверные географические границы.
6. Кнопка перехода вызывает `onStartPlanning`. Компонент не хранит второй выбранный район, не меняет choices и не делает HTTP-запросов.
7. Адаптируй под 1440×900, 768×1024 и 390×844. Обеспечь выбор района клавиатурой через обычные кнопки; интерактивный SVG не должен быть единственным управлением.
