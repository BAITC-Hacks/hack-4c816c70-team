# Следующий проход после локализации и сообщения Тамерлана

Архитектор сейчас моделирует достопримечательности в `city-scene-engine.ts` и `city-landmarks.ts`. Эти два файла не редактировать другим агентам. API-владелец сообщил о локальном commit 14c3337: Accept-Language ru-RU/kk-KZ/en-US, explanationLocale, Content-Language, переводы mock/live/fallback. Проверить опубликованный контракт после push, не считать сообщение заменой чтения Swagger.

## Claude 1 — язык и доступность интерфейса (25 минут)

Проверить свои features/city-overview и components/ui в RU/KK/EN: естественность казахского и английского, все видимые строки, aria-label/title, переключатели темы/языка, длинные подписи, единицы/множественные формы. Все три темы, 390/1440, 200% zoom, клавиатура, сохранение выбранного района/языка/темы при переходе. Исправлять только свои подтверждённые дефекты; useLocale и app принадлежат GPT. 3D engine/landmarks не трогать, они сейчас у архитектора. Отчёт обновить фактами и доступными путями скриншотов, без нового дизайна и зависимостей. Git — GPT.

## Claude 2 — приёмка решений на трёх языках (25 минут)

Пройти в общем приложении /decisions на RU/KK/EN: контрольный набор, изменение языка при заполненном плане, пустой район, шестая мера, бюджет, третья мера направления, глобальная и районная несовместимость, устаревшее назначение района, удаление/возврат меры. Проверить отсутствие русских фрагментов в переведённых причинах, отсутствие overflow на 390, раскрытие/закрытие плана и возврат фокуса. Показать, что одинаковые IDs и районы сохраняются при переводе. До подтверждённого подключения Accept-Language серверный язык не считать проверенным; после подключения GPT повторить реальный POST на kk/en. Редактировать только planner и свой отчёт, не менять API или формулу. Git — GPT.

## GPT — новый серверный языковой контракт

После push Тамерлана получить origin и безопасно интегрировать новый API-контракт. Тамерлан использует свой аккаунт TamerlanWebd: правило Hizeshi относится к нашим агентам, а не меняет авторство команды. Локальный номер 14c3337 может измениться, читать фактически опубликованный commit.

В API client передавать Accept-Language выбранного языка, неизменное тело choices. Адаптер принимает explanationLocale; UI показывает фактический язык пришедшего объяснения. Убрать безусловную пометку русского текста, использовать сравнение языка ответа и интерфейса. При смене языка после результата не приписывать старому тексту новый язык и не отправлять POST автоматически; явное повторное получение объяснения допустимо через согласованный evaluate. Сохранить защиту от двойного POST/stale response. Контрактные тесты и реальные ответы на ru/kk/en: 95 / 56.54, корректный explanationLocale и локализованный mock. Сетевые ошибки переводить по стабильному code. Проверить memory fallback LocaleProvider при отказе storage (см. localization-review.md). Интеграция и commit/push от Hizeshi, без включения незавершённого 3D архитектора; далее передать SHA для единого деплоя.
