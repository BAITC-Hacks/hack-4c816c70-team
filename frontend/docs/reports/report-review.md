При удалении строки корзины теперь выбирается следующая кнопка удаления, при удалении последней строки — предыдущая, если корзина пуста — заголовок «План». Ключ строки больше не содержит индекс, поэтому остальные строки не размонтируются после удаления.

Независимая проверка интегратора на `localhost:3000/decisions` через браузерный инструмент:

- 390 px: Enter на добавлении M7 → активная кнопка «Убрать», `:focus-visible=true`.
- Удаление единственной M7 → активный H2 «План», `:focus-visible=true`.
- Escape после удаления → активный переключатель корзины.
- M7 + M14: удаление M7 → активная кнопка «Убрать M14 из плана».
- 1440 px: добавление и удаление через карточку сохраняют фокус на действии; кольцо фокуса подтверждено скриншотом.
- На обеих ширинах горизонтальное переполнение 0; console error/warn пусты. Оценки через API не отправлялись.
