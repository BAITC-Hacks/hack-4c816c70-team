# Модель города — архитектурный проход 23 сентября

Авторские процедурные модели созданы в `features/city-overview/city-landmarks.ts`, подключены в `city-scene-engine.ts`. Другие интерфейсы, API и словари локализации не изменялись этим проходом.

## Добавлено

- EXPO «Нұр Әлем»: стеклянная сфера, горизонтальные/вертикальные рёбра фасада, круглая площадь и низкие павильоны.
- Хан Шатыр: изогнутый эллиптический шатёр со смещённой вершиной, рёбра покрытия, мачта и входная группа.
- Дворец мира и согласия: стеклянная пирамида с каркасом и ступенчатым основанием.
- Существующий Байтерек сохранён; вокруг памятников зарезервированы площадки, случайные здания там не возникают.
- Четыре мостовых перехода: два автомобильных и два арочных, с опорами, ограждениями и подвесами.
- Набережные, деревья, световые точки, пешеходный бульвар с фонтанами.
- Улицы привязаны к мостам; плотные низкие кварталы и отдельная группа высотных зданий, этажные полосы фасадов.

Это стилизованный макет, не географическая реконструкция. Высоты и положение объектов не кодируют показатели API. Подпись о схематичности уже локализована предыдущим этапом.

## Производительность и ресурсы

Внешние модели, текстуры, платные API и новые npm-зависимости не добавлены. Мелкие неподвижные детали объединяются по материалам через утилиту установленного Three.js. Жилые здания, этажные полосы, дорожные сегменты, деревья и фонари используют instancing. Сохранены render-on-demand, ограничение pixel ratio, остановка вне viewport/скрытой вкладки и reduced motion. Добавлена очистка новых геометрий/материалов и всех instanced meshes при unmount.

## Проверки

- ESLint двух модулей и общая TypeScript-проверка успешны.
- Отдельная проверка модели в Node: конечные координаты всех вершин, 11 mesh-объектов после batching, 19 596 треугольников с учётом instancing (только новый модуль landmarks), переключение материалов и dispose без ошибок.
- В браузере localhost:3000: дневная/ночная темы, сцена видима, ошибок/warnings нет.
- DOM-выбор Нұры сохраняется при /decisions → /; canvas на /decisions отсутствует, после возврата один.
- Для перехода на mobile сохраняется ранее реализованный статичный/скрытый вариант hero; 3D не становится обязательным управлением.
- Проверка реальной слабой видеокарты и измерение FPS не выполнялись; производительность не заявляется конкретным числом кадров.
- Повторный общий lint/build во время работы GPT над explanationLocale временно упал в его изменяемых use-simulation.ts, ResultMessages и тестовом EvaluationVM. Новые 3D-модули отдельно проходят lint и геометрическую проверку; деплой допустим после завершения интеграции и успешной общей сборки.

Визуальные формы сверены с официальными страницами [QazExpoCongress — Нұр Әлем](https://qazexpocongress.kz/ru/nur-alem/) и [Хан Шатыр](https://site.khanshatyr.com/en). Чужие модели, фотографии и текстуры не копировались.
