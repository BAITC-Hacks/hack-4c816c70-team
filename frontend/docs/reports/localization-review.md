## Замечание GPT перед фиксацией

P2: в `lib/i18n/LocaleProvider.tsx` setLocale при ошибке localStorage.setItem только отправляет событие; readLocale затем снова читает старое значение или возвращает ru. Поэтому комментарий «disabled storage must not prevent language switching» не соответствует поведению. Нужен рабочий in-memory fallback состояния языка при недоступном/заполненном storage, без потери синхронизации и без hydration mismatch. Проверить отдельно, не меняя правила симуляции. Это замечание по коду, не браузерная имитация отказа storage.
