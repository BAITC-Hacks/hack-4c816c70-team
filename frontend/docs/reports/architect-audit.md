# Независимая проверка кода — 23.09.2026

База: `53ee806`. Проверка выполнена интегратором в отдельной рабочей копии, независимо от отчётов исполнителей. Код backend не менялся.

## Просмотренные участки

- Сервер: ChoiceValidator, ScoreCalculator, SimulationEndpoints, ExplanationService, OpenAiExplanationClient. Проверены порядок расчёта, округление на границе ответа, обязательность района, конфликты, ограничение бюджета, синергии и резервное объяснение.
- Frontend: API client/adapter/errors, состояние симуляции и reducer, восстановление черновика, ResultsPage, локализация, правила выбора, CityScene и освобождение ресурсов сцены.
- Score и эффекты не пересчитываются в UI. Reducer отклоняет старый ответ после reset и блокирует изменение набора во время оценки. При смене языка отправка выполняется явно.

## Найдено и исправлено

`normalizeApiError(null, 503)` выбрасывал `Cannot read properties of null (reading 'error')`. Пустое тело HTTP-ошибки превращается в null в API client, поэтому обработчик ошибочно классифицировал полученный ответ сервера как сетевой сбой и терял HTTP status.

Добавлена проверка формы error envelope. Теперь пустое тело и повреждённые поля дают безопасную HTTP-ошибку с исходным status; документированные message/code сохраняются. Добавлен regression-тест десяти вариантов тела. До исправления исключение воспроизведено отдельно.
