# Кастомные списки — 23.09.2026

На базе `a39c844` заменены системные выпадающие меню районов в корзине и языка в шапке. Общий Select использует цвета трёх тем, отметку выбранного пункта, пункты от 44 px и анимацию с поддержкой reduced motion. Portal в body исключает обрезку прокручиваемой корзиной; положение учитывает доступное место сверху и снизу.

Клавиатура: стрелки, Home/End, выбор Enter/Space, поиск по первым буквам, Escape без закрытия родительской корзины и Tab. Конфликтующие районы остаются недоступными; API и правила расчёта не менялись.

Проверки интегратора: lint, production build, typecheck, 74/74 существующих теста. После финальной замены pointerdown на mousedown повторена проверка типов; это сохраняет фокус при выборе и позволяет прокручивать меню касанием.

Браузер: общий компонент проверен через меню языка на 390 и 1440 px, день/ночь, выбор мышью и Home/Enter, Escape, Tab; переполнение desktop 0. Скриншоты меню просмотрены. Во время проверки локальная страница не получила scenario от настроенного API, поэтому назначение района в реальной корзине повторно не проверено; его подключение проверено по коду и сборкой. Физическое касание и скринридер не проверены. Расчёты через API не запускались.
