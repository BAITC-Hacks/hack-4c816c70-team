# Запуск работы трёх аккаунтов

Этот пакет подготовлен для существующего Next.js проекта. Интерфейс приложения ещё предстоит реализовать.

1. Передайте каждому аккаунту один и тот же архитектурный commit репозитория и доступ к исходным документам в `docs/reference/` от корня.
2. Claude №1 получает целиком [своё задание](tasks/claude-1.md): визуальная система и обзор города.
3. Claude №2 получает целиком [своё задание](tasks/claude-2.md): конструктор пяти решений и проверки выбора.
4. GPT получает целиком [своё задание](tasks/gpt.md): API, состояние, результаты и интеграция.
5. Тамерлану передаётся [список вопросов по контракту](backend-handoff.md). В commit `8117017` уже добавлены endpoints и правила; GPT сверяет live Swagger и подключает их. Реальная интеграция не объявляется готовой до проверки запросов.
6. Каждый аккаунт сдаёт commit/diff и отчёт. Передавайте их в задачу архитектора для проверки по [чек-листу](acceptance.md).

Общие решения: [архитектура](architecture.md), [дизайн](design.md), [правила работы](../AGENTS.md), [интерфейсы компонентов](../lib/contracts/ui.ts).

Аккаунты работают параллельно в отдельных клонах/ветках либо в непересекающихся файлах общего каталога. Доступ архитектора к другим аккаунтам не предполагается; сами задания не запускают их автоматически.

## Проверено при передаче архитектуры

23 сентября 2026: зависимости установлены по существующему lockfile (`npm ci --ignore-scripts --no-audit --no-fund`), `npm run lint` и `npm run build` завершились успешно. Build включал проверку TypeScript, в том числе нового UI-контракта. Это проверка исходного каркаса и архитектурного пакета; экраны, реальный API и браузерный сценарий ещё не реализованы и не проверены.
