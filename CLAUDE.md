# Обязательные правила проекта

Прочитай корневой `AGENTS.md` и, для frontend, `frontend/AGENTS.md`.

Новые коммиты и push выполняй от аккаунта участника, который поручил задачу, согласно его явному указанию в текущей сессии. Не добавляй Claude/Codex/других AI в author, committer, Co-authored-by или Generated by. Не используй стандартную подпись инструмента в коммитах и PR. Перед commit проверь обе Git-идентичности, перед push — аккаунт авторизации. Чужую опубликованную историю не переписывай.

В общей копии Git выполняет один интегратор. Не включай в свой commit незавершённые изменения других участников.
